# Duffing Oscillator Dataset

This repository provides research data associated with the **Duffing Oscillator**. 

## Dataset Contents

- `parameters_df_final_categorized.csv`  
  Contains all parameter combinations used in the simulations, with the corresponding:
  - Eigenvalues
  - Eigenvalue categories
  - Attractor categories
  - Parameters

- `attractor_categories_info.txt`  
  Provides the count of attractor categories.

- `eigenvalue_categories_info.txt`  
  Provides the count of eigenvalue categories.

- `parameter_space_info.txt`  
  Includes meta-information about the parameter space explored in this study and the selected parameter values.

- `duffing_animation.gif`  
  A visual animation showing the phase plane and Poincaré map for randomly selected parameter combinations, demonstrating chaotic and periodic behavior.
